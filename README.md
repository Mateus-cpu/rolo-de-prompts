# Rolo

703 prompts de vídeos feitos com Claude Opus 5.5, cada um ao lado do vídeo que gerou.

Site: https://mateus-cpu.github.io/rolo-de-prompts/

## Créditos

- Dados: [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos), licença MIT (cópia em `LICENCA-ORIGEM.txt`).
- Cada prompt e cada vídeo pertence ao autor creditado no quadro.
- Imagens e vídeos são carregados de media.skillry.dev.
- Projeto independente, sem vínculo com a Anthropic nem com o Skillry.

## Atualizar

`python3 -I gerar.py <pasta do repositório de origem> <arquivo com o resultado da checagem dos vídeos>` refaz o `dados.js`.
